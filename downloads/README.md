Version10 (`0.10.0-fitness-duration`) enthält den erfolgreichen Health-Importfix, lesbare Scroll-Aufnahmen und die ausdrücklich getrennte Quellzeitspanne. Bei einem importierten Training kann in Fitness oder Trainingsjournal zusätzlich **Trainingszeit im Quellzeitfenster prüfen** gewählt werden. Der SDK-Wert bleibt ein Zeitfenster-Aggregat; er wird nicht als geschätzte aktive Einzeldauer oder Trainingsenergie ausgegeben.

Als Update von **EG · Watch-Test** installieren: gleiches Paket `de.ernaehrung.demo.watchspike`, gleiche bisherige Testsignatur. Bestehende Apps und persönliche Daten nicht zur Umgehung einer Signaturmeldung löschen. Room19 erhält die bisherigen Daten. Ältere APKs bleiben als Nachweise erhalten; für eine bereits auf Room19 aktualisierte Datenbank Version10 oder neuer verwenden.
